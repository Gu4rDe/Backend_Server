# Модели для распознавания лиц

Для работы системы требуются модели детекции и распознавания.

## 1. insightface buffalo_l (детекция + выравнивание)

Основной пайплайн использует **insightface** с модельным паком `buffalo_l`:
- **SCRFD-10GF** — детекция лиц с 5-точечными ландмарками
- **ArcFace ResNet-50** — извлечение эмбеддингов (резервный, если AdaFace недоступен)
- **2d106det** — 106-точечные ландмарки (опционально)

Модель скачивается автоматически при первом запуске в `~/.insightface/models/buffalo_l/` (~32 MB).

```bash
# Предварительная загрузка (опционально)
python -c "from insightface.app import FaceAnalysis; app = FaceAnalysis(name='buffalo_l'); app.prepare(ctx_id=-1)"
```

### Параметры SCRFD:
- **Вход:** 640x640 BGR изображение
- **Выход:** bounding boxes, confidence scores, 5 ключевых точек
- **Порог:** настраивается через `conf_threshold` (по умолчанию 0.5)

## 2. AdaFace IR-101 (распознавание — резервный путь)

Если insightface недоступен, система переключается на ONNX-модели напрямую:
- **SCRFD det_10g.onnx** — детекция лиц
- **adaface_ir101.onnx** — извлечение 512-мерных эмбеддингов

### Конвертация AdaFace из PyTorch:

```bash
cd scripts
python convert_adaface_to_onnx.py
```

Скрипт скачает веса IR-101 (MS1MV3) и сконвертирует в ONNX.

### Параметры AdaFace:
- **Архитектура:** AdaFace IR-101
- **Вход:** 112x112 BGR изображение, нормализация (pixel - 127.5) / 128.0
- **Выход:** 512-мерный L2-нормализованный эмбеддинг (float32)
- **Выравнивание:** 5-точечное similarity transform (norm_crop)

## 3. CLAHE препроцессинг

Перед детекцией применяется CLAHE (Contrast Limited Adaptive Histogram Equalization):
- **Параметры:** clipLimit=2.0, tileGridSize=(8, 8)
- **Цветовое пространство:** BGR → LAB → CLAHE на L канале → LAB → BGR
- **Назначение:** улучшение детекции в условиях плохого освещения

## 4. Формат эмбеддингов

- **Размерность:** 512
- **Тип данных:** float32 (2 KB на эмбеддинг)
- **Хранение:** LargeBinary в SQLite, сериализация через `serialize_embedding()`
- **Десериализация:** `deserialize_embedding()` с автоопределением float64 legacy

## Требования к качеству моделей

Для достижения 90% точности:
- Модель детекции должна иметь высокий recall (не пропускать лица)
- Модель эмбеддингов должна хорошо различать разные лица и давать схожие эмбеддинги для одного человека при разных условиях освещения, поз и выражений лица
