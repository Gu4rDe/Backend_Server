# Предобученные модели для распознавания лица

Для работы системы требуются следующие модели:

## 1. Модель детекции лиц (MediaPipe)

В текущей реализации используется MediaPipe Face Detection для обнаружения лиц.
Не требует загрузки дополнительных файлов — устанавливается через pip.

```bash
pip install mediapipe
```

## 2. Модель извлечения эмбеддингов (ArcFace ONNX)

В продакшене используется ArcFace (ResNet-100) в формате ONNX для извлечения 512-мерных эмбеддингов.

### Скачивание модели:

```bash
# Перейдите в директорию models
cd models

# Скачайте ArcFace модель
Invoke-WebRequest -Uri "https://huggingface.co/garavv/arcface-onnx/resolve/main/arc.onnx?download=true" -OutFile "arcface.onnx"
```

### Параметры модели:
- **Архитектура:** ArcFace ResNet-100
- **Вход:** 112x112 RGB изображение
- **Выход:** 512-мерный эмбеддинг
- **Размер файла:** ~130 MB
- **Источник:** https://huggingface.co/garavv/arcface-onnx

## 3. Fallback режим

Если файл `arcface.onnx` не найден в директории `models/`, система автоматически переключается на упрощённый метод на основе гистограмм. Этот режим подходит только для тестирования — точность распознавания значительно ниже.

## Требования к качеству моделей

Для достижения 90% точности:
- Модель детекции должна иметь высокий recall (не пропускать лица)
- Модель эмбеддингов должна хорошо различать разные лица и давать схожие эмбеддинги для одного человека при разных условиях освещения, поз и выражений лица
