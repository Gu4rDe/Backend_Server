# ML-модели распознавания лиц — Методичка

## 1. Обзор

Сервер использует модельный пакет **insightface buffalo_l** — единственный провайдер распознавания лиц. Пакет включает:

| Компонент      | Модель            | Назначение                          |
| -------------- | ----------------- | ----------------------------------- |
| Детекция       | SCRFD-10GF        | Обнаружение лиц на изображении      |
| Эмбеддинги     | ArcFace R50       | извлечение 512-мерного вектора лица |
| Выравнивание   | 2d106 / 3d68      | ключевые точки для norm_crop       |
| Атрибуты       | Gender & Age      | определение пола и возраста (не используется) |

Размер пакета: **~326 МБ**. Модель скачивается автоматически при первом запуске в `~/.insightface/models/buffalo_l/`.

## 2. SCRFD-10GF — Детекция лиц

**SCRFD** (Sample and Computation Redistribution for Efficient Face Detection) — one-stage детектор лиц с перераспределением вычислений.

### Принцип работы

1. **Backbone** извлекает много масштабные признаки изображения
2. Три выхода с stride 8×, 16×, 32× — обнаружение лиц разного размера (маленькие, средние, крупные)
3. Каждый выход предсказывает:
   - **Bbox** — координаты прямоугольника (x1, y1, x2, y2)
   - **Confidence** — вероятность наличия лица (det_score)
   - **5 ключевых точек** — левый глаз, правый глаз, нос, левый угол рта, правый угол рта
4. **NMS** (Non-Maximum Suppression) удаляет дублирующие детекции

### Параметры в проекте

```python
FaceAnalysis(name="buffalo_l", providers=["CPUExecutionProvider"])
app.prepare(ctx_id=-1, det_size=(640, 640))
```

- `ctx_id=-1` — работа на CPU
- `det_size=(640, 640)` — размер входа детектора
- Порог уверенности: **0.5** (`conf_threshold`) — лица с `det_score < 0.5` отбрасываются

### Результат детекции

```python
FaceResult(
    bbox=[x, y, w, h],       # bounding box в формате xywh
    embedding=np.ndarray,      # 512-мерный вектор float32
    confidence=float,          # det_score
)
```

## 3. ArcFace R50 — Извлечение эмбеддингов

**ArcFace** (Additive Angular Margin Loss for Deep Face Recognition) — модель на базе ResNet50, обученная на датасете WebFace600K (~600K идентичностей).

### Принцип работы

1. **Вход**: выровненное лицо 112×112 RGB
2. **Backbone**: ResNet50 извлекает признаки
3. **Выход**: 512-мерный вектор `float32`
4. **ArcFace Loss** во время обучения добавляет угловой запас (angular margin) между классами, что делает embeddings более разделимыми в пространстве
5. **L2-нормализация** превращает embeddings в единичные векторы — косинусное сходство совпадает со скалярным произведением

### Нормализация эмбеддинга

```python
embedding = face.embedding.astype(np.float32)
norm = np.linalg.norm(embedding)
if norm > 0:
    embedding = embedding / norm
```

После нормализации `||embedding|| = 1`, косинусное сходство = `dot(emb1, emb2)`.

## 4. Выравнивание лица (Face Alignment)

### Ключевые точки

Модель `2d106` определяет 106 точек лица, но для выравнивания используется подмножество из **5 ключевых точек**:

| Точка | Описание          |
| ----- | ----------------- |
| 0     | Левый глаз        |
| 1     | Правый глаз       |
| 2     | Кончик носа        |
| 3     | Левый угол рта    |
| 4     | Правый угол рта   |

### Similarity Transform

По 5 точкам вычисляется **2D similarity transform** (поворот + масштаб + сдвиг), которая преобразует координаты лица на исходном изображении в координаты на шаблоне 112×112. Это устраняет влияние наклона головы, масштаба и положения лица на фото.

Результат: обрезанное и выровненное лицо 112×112 — вход для ArcFace.

## 5. Полный пайплайн обработки

### Регистрация сотрудника (`POST /api/v1/employees/register`)

```
Изображение (3 фото)
      │
      ▼
Декодирование (OpenCV → BGR numpy)
      │
      ▼
CLAHE-препроцессинг
  BGR → LAB
  Усиление канала L (clipLimit=2.0, tileGridSize=8×8)
  LAB → BGR
      │
      ▼
SCRFD-10GF детекция
  det_size=(640,640), порог 0.5
  Валидация: ровно 1 лицо на фото
      │
      ▼
Выравнивание (5-точечная similarity transform → 112×112)
      │
      ▼
ArcFace R50 → 512-dim float32 embedding
      │
      ▼
L2-нормализация
      │
      ▼ (для каждого из 3 фото)
Усреднение: mean(embeddings) → L2-norm
      │
      ▼
Шифрование AES-256-GCM → BLOB в БД
```

### Распознавание лица (`POST /api/v1/faces/recognize`)

```
Изображение (1 фото)
      │
      ▼
Декодирование → CLAHE → SCRFD-10GF
      │
      ▼ (для каждого найденного лица)
Выравнивание → ArcFace → L2-norm
      │
      ▼
Загрузка всех сотрудников с embeddings из БД
      │
      ▼
Дешифровка AES-256-GCM → numpy массивы
      │
      ▼
Матричное умножение: known_embeddings @ query_embedding
      │
      ▼
Косинусное сходство > threshold (default 0.4) → совпадение
```

## 6. Хранение эмбеддингов

### Шифрование (AES-256-GCM)

Эмбеддинги шифруются перед записью в БД и расшифровываются при чтении.

**Формат BLOB в БД:**

```
[0x01 версия] [12 байт nonce] [шифротекст + 16 байт GCM-тег]
```

- Префикс `0x01` — маркер версии, отличает зашифрованные данные от устаревших
- 12 байт nonce — уникальный для каждого эмбеддинга
- Шифротекст: 2048 байт (512 × float32)
- 16 байт GCM-тег — обеспечение целостности

### Обратная совместимость

Устаревшие форматы определяются по отсутствию префикса `0x01`:

| Размер      | Формат             | Обработка                          |
| ----------- | ------------------ | ---------------------------------- |
| 2048 байт   | float32 без шифра  | `np.frombuffer(data, dtype=float32)` |
| 4096 байт   | float64 без шифра  | `np.frombuffer(data, dtype=float64).astype(float32)` |
| >2048 байт  | зашифрованный      | расшифровка → float32               |

### Ключ шифрования

`ENCRYPTION_KEY` — Base64-закодированный 256-битный ключ, генерируется при первом запуске. **Смена ключа делает все хранимые эмбеддинги нечитаемыми — пути миграции нет.**

## 7. Сравнение лиц

### Косинусное сходство

Для двух L2-нормализованных векторов `a` и `b`:

```
similarity = dot(a, b) = Σ(a[i] × b[i])
```

Значение от -1 до 1, где 1 = полное совпадение.

### Батчевое сравнение

При распознавании матрица известных эмбеддингов умножается на вектор запроса:

```python
similarities = known_embeddings @ query_embedding  # shape: (N,)
```

Все N сравнений за одну операцию — быстрее поэлементного цикла.

### Порог (threshold)

- Значение по умолчанию: **0.4**
- Настраивается через `AppSettings.match_threshold`
- При `similarity > threshold` — совпадение засчитывается
- Результаты сортируются по убыванию similarity

## 8. CLAHE-препроцессинг

**CLAHE** (Contrast Limited Adaptive Histogram Equalization) — улучшение контраста перед детекцией.

```python
def apply_clahe(image, clip_limit=2.0, tile_grid_size=(8, 8)):
    lab = cv2.cvtColor(image, cv2.COLOR_BGR2LAB)
    l, a, b = cv2.split(lab)
    clahe = cv2.createCLAHE(clipLimit=clip_limit, tileGridSize=tile_grid_size)
    l = clahe.apply(l)
    lab = cv2.merge([l, a, b])
    return cv2.cvtColor(lab, cv2.COLOR_LAB2BGR)
```

- Перевод в цветовое пространство LAB
- Усиление канала яркости L с ограничением контраста (clipLimit=2.0)
- Размер сетки: 8×8 пикселей
- Возврат в BGR для подачи в SCRFD

Цель: улучшить видимость лиц при плохом освещении, неравномерной экспозиции, бликах.

## 9. Примечание

### Метрики точности (бенчмарки buffalo_l)

| Бенчмарк    | Описание                                                      | Точность |
| ----------- | ------------------------------------------------------------- | -------- |
| MR-ALL      | Общая точность на мультирасовом бенчмарке (все расы)          | 91.25%   |
| · African   | —— то же, только лица африканской внешности                  | 90.29%   |
| · Caucasian | —— то же, только лица европейской внешности                   | 94.70%   |
| · South Asian | —— то же, только лица южноазиатской внешности               | 93.16%   |
| · East Asian | —— то же, только лица восточноазиатской внешности            | 74.96%   |
| LFW         | Верификация: один ли человек на двух лобовых фото?            | 99.83%   |
| CFP-FP      | Верификация: лобовое фото vs. профильное                      | 99.33%   |
| AgeDB-30    | Верификация при разнице в возрасте 30+ лет                    | 98.23%   |
| IJB-C (E4)  | Правительственный бенчмарк: видео + сложные условия           | 97.25%   |

**MR-ALL 91.25%** — при фиксированном уровне ложныхAccept (FAR) модель правильно опознаёт 91.25% лиц на смешанном мультирасовом датасете. Расовый разброс: лучше всего на европейских лицах (94.70%), хуже всего на восточноазиатских (74.96%).

**LFW 99.83%** — почти безошибочная верификация на высококачественных лобовых фото. В реальных условиях (плохое освещение, ракурс, размытие) точность ниже.

**CFP-FP** — тест на сопоставление лобового и профильного фото, измеряет устойчивость к изменению ракурса.

**AgeDB-30** — тест на устойчивость к старению: сравниваются фото одного человека с разницей 30+ лет.

**IJB-C(E4)** — бенчмарк NIST/IJB с видео, сложными условиями (разные освещения, ракурсы, перекрытия).

### Производительность на CPU

- Провайдер: `CPUExecutionProvider` (onnxruntime)
- GPU не требуется и не используется
- Скорость: ~200–500 мс на изображение (зависит от CPU и количества лиц)
- Потребление памяти: ~500 МБ RAM (модель + runtime)

### Размер модели и зависимости

- Размер пакета buffalo_l: **~326 МБ**
- Автозагрузка при первом запуске в `~/.insightface/models/buffalo_l/`
- В Docker — скачивается через `entrypoint.sh`
- Зависимости: `insightface==0.7.3`, `onnxruntime==1.23.2`, `onnx==1.16.0`, `opencv-python-headless==4.8.0.76`

### Ограничение Python

- Поддерживаемые версии: **Python ≥3.10, <3.13**
- Python 3.13+ не поддерживается из-за проблем совместимости onnxruntime и insightface

### Лицензия моделей

Модели insightface предоставляются **только для некоммерческого исследовательского использования** (non-commercial research purposes only). Для коммерческого использования необходимо получить лицензию от DeepInsight.
